# 牛客题目链接导入

创建题目页面顶部，粘贴链接后点击“读取题目”，检查预览，再点击“确认填入表单”。导入只填入表单，最终点击“保存”才创建本地题目，原有草稿在确认填入前不会被替换。

支持 HTTPS 链接：

- https://ac.nowcoder.com/acm/contest/比赛编号/题号
- https://ac.nowcoder.com/acm/problem/题目编号
- https://www.nowcoder.com/practice/32位题目UUID

链接中的分享参数与锚点会被去除。能够取得牛客 problemId 时统一使用 `NC{problemId}` 作为外部题目标识，兼容同一道题的不同链接，沿用现有题目标识唯一约束避免重复保存。

接口：`POST /api/problems/import/nowcoder`，JSON 请求体 `{"url":"牛客题目地址"}`，需要登录和 CSRF。返回 platform、externalProblemKey、title、sourceUrl、difficulty、tags、contentMd、warnings。难度保留牛客公开的数值，未知难度/标签留空提示。

练习题使用牛客公开页面实际调用的 `/practice/terminal/{uuid}` JSON 数据；竞赛题解析公开 HTML。保留题目描述、输入输出、样例换行及公式图片，转换为 Markdown，不导入网站脚本、按钮、题解或隐藏测试数据。

请求只允许固定牛客域名和严格匹配的题目路径，不跟随重定向，不携带用户 Cookie。响应大小限制 2 MiB，连接超时 5 秒，读取超时 8 秒。登录限制、付费题、非公开题、接口变化或访问限制时返回明确错误，不尝试绕过访问控制，可继续手动填写。

验证：解析和 URL 安全单元测试、接口认证/CSRF 测试、前端预览/确认/失败保留草稿测试。使用 `-Dnowcoder.live-check=true` 可额外验证公开竞赛题、题库题、练习题三个真实链接。
