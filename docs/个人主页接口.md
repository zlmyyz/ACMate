# 个人主页、关注与收藏

个人主页位于 `/users/:id`，顶部昵称和头像均可进入自己的主页。左侧按头像、昵称、关注数、编辑或关注按钮、IP 属地、所在地、性别、GitHub、贡献统计排列；右侧仅包含刷题统计、每日提交热力图和最近 10 条提交。编辑按钮仍进入 `/settings/profile`，不显示全站排名或声望。

## 头像和资料

`app_user.avatar_url` 专门保存上传头像。没有上传头像时，根据已绑定的 GitHub 数字 ID 使用 GitHub 头像；没有 GitHub 时使用前端 `/default-avatar.svg`。加载失败时使用默认头像。GitHub 解绑后会重新计算头像来源，不会把 GitHub 头像写入上传字段。

`PUT /api/users/me/profile` 新增可选字段 `location`（最多 128 字）、`gender`（`MALE`、`FEMALE`、`PRIVATE` 或空字符串）。空字符串可清空所在地、性别和简介。用户公开资料接口也包含这两个字段。

## 关注与贡献

| 方法 | 接口 | 说明 |
| --- | --- | --- |
| GET | `/api/users/{id}/summary` | 关注数、粉丝数、当前访问者是否关注、IP 属地、贡献统计 |
| GET | `/api/users/{id}/following?page=1&size=20` | 分页关注列表 |
| GET | `/api/users/{id}/followers?page=1&size=20` | 分页关注者列表 |
| PUT | `/api/users/{id}/follow` | 关注，必须登录并携带 CSRF |
| DELETE | `/api/users/{id}/follow` | 取消关注，必须登录并携带 CSRF |
| GET | `/api/posts/{id}/favorite` | 当前用户收藏状态及总收藏数 |
| PUT | `/api/posts/{id}/favorite` | 收藏帖子，必须登录并携带 CSRF |
| DELETE | `/api/posts/{id}/favorite` | 取消收藏，必须登录并携带 CSRF |

关注和收藏使用数据库联合主键防止重复，接口幂等。不能关注自己、不能关注停用账号或收藏停用帖子。取消操作不会删除其他用户的关系。

贡献统计中，总阅读沿用帖子的真实浏览数，昨日阅读由 `post_daily_views` 按上海日期累积，新功能上线前未采集的每日阅读无法还原。点赞、收藏总数和昨日数据来自仍有效的记录及其创建时间；取消操作会相应减少计数。统计仅包含当前可见的正常帖子。账号合并同时迁移并去重关注、粉丝和收藏，防止形成自关注。

## OJ 预留接口

仅查询本站已存储的 `oj_submission`、`oj_first_ac` 等数据，不会向外部 OJ 发起请求。

- `GET /api/users/{id}`：现有 `ojStats` 字段提供累计、近 30 天、近 7 天通过数及最近通过时间。
- `GET /api/users/{id}/activity`：返回 `start`、`end`、`submissions`、`activeDays`、`days: [{ date, count }]`。按上海日期覆盖近 365 天，未提交日期补零。
- `GET /api/users/{id}/submissions/recent`：按 `submitted_time DESC, id DESC` 返回最多 10 条记录，字段为 `id`、`platform`、`problemKey`、`problemId`、`title`、`verdict`、`language`、`submittedTime`。重复提交保留，站内题目不可用时 `problemId` 为 null。

没有 OJ 数据时返回零值、空数组，页面显示空状态。未来 OJ 对接写入已有表后，这些接口直接生效；本次不新增外部 OJ 接入或抓取。

## 离线 IP 属地

成功登录后通过 AOP 记录时间与连接 IP，使用服务器内置的 ip2region IPv4/IPv6 XDB 文件查询地区，用户 IP 不发送给外部服务。公开接口只显示地区，不暴露原始登录 IP。

默认读取 Servlet 的 `remoteAddr`，不信任任意客户端传入的转发头。本机/局域网显示“本地网络”。生产环境如使用反向代理，需要仅在受信任代理处配置真实来源 IP；否则识别到的会是代理地址。

地址库来源：[ip2region 官方仓库](https://github.com/lionsoul2014/ip2region)。资源目录为 `src/main/resources/geolocation/`，附上游许可证；数据为开发时下载的离线快照，后续可替换更新。
