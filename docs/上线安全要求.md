# 上线前安全要求

## 判题服务

判题执行不可信代码。`deploy/judge/compose.yml` 当前使用 `privileged: true`；上游 go-judge 的 Docker 示例同样使用特权模式，不能仅凭移除该选项就断定沙箱仍可安全工作。它应只部署到专用 VM 或专用宿主机，不能与网站、MySQL、Redis、源码或生产凭据共用宿主机；当前本机 compose 只适合开发调试，不具备对学生开放的证明。

独立环境应配置私网或经认证的安全隧道，防火墙只允许应用服务器访问判题 API，不向公网暴露 5050 端口。示例 compose 的 127.0.0.1 绑定只允许同一宿主机访问，跨 VM 使用时必须配置受限的隧道或访问策略，不能简单改为 0.0.0.0。显式阻断判题环境访问网站、数据库、元数据服务及互联网；沙箱自身的网络、文件系统和进程隔离需要在目标内核和实际镜像上逐项测试。不要挂载宿主机敏感目录或 Docker socket。

现有请求限制包括：单后端运行槽 1 个；每账号每分钟最多 30 次自测请求（Redis 不可用时拒绝运行）；编译 CPU 20 秒、墙钟 40 秒、内存 768 MiB；运行 CPU 2 秒、墙钟 5 秒、内存 256 MiB；每任务进程 64 个；stdout 64 KiB、stderr 16 KiB。容器整体上限 2 核、2 GiB、256 进程。以上是配置，不代表所有限制已在目标机器上验证；多后端实例必须额外使用共享排队或共享并发控制。

判题默认关闭，一键启动不会启动本机判题容器。仅在本机开发需要时执行项目上级目录的 `启动前后端.bat judge`，或显式设置环境变量 `ACMATE_PRACTICE_MODE=local`，如果后端已经运行，需要重启后端才能应用模式；此模式只允许直连本机回环地址的请求运行判题，且拒绝携带代理转发头的请求；状态接口对其他地址返回不可用。此检查只是额外防线，代理可能隐藏原始客户端地址，所以 Nginx 或其他网关在完成隔离前必须明确禁止向外转发 `/api/practice/run`，不得依赖它作为唯一安全边界。部署和验收独立 VM 后，显式设置环境变量 `ACMATE_PRACTICE_MODE=isolated` 才允许远程自测；该设置只是操作员声明，并不能证明沙箱已经隔离。

向学生开放前，在隔离的目标 VM 上启用 `practice.sandbox-check=true` 运行集成测试，并补做内存耗尽、进程创建、网络外连、宿主文件访问和并发压力测试。当前没有目标 VM，因此不能声称这些验证已完成。

## 注册、缓存和代理

邮箱服务未启用或 Redis 不可用时暂停邮箱注册；已绑定 GitHub 可以继续登录，新的 GitHub 身份仍可创建账号。Redis 用于验证码、限流、题库热门首页和公开样例短期缓存；密码登录限流在 Redis 不可用时关闭登录。讨论和排行榜列表直接查询数据库。题库首页缓存使用 MySQL 事务内更新的版本号：题目新增、修改、停用或恢复后，新请求不再使用旧版本缓存；旧键按 TTL 自动过期。短期样例缓存按原题链接区分，最长 10 分钟。

默认不信任代理头。反向代理部署时，把可信代理的**具体 IP 地址**通过环境变量 `TRUSTED_PROXY_IPS` 配置为逗号分隔列表，并确保代理防火墙只允许可信来源；服务从右往左解析 X-Forwarded-For，遇到第一个非可信 IP 即停止。不要将公网用户地址配置为可信代理。当前不支持 CIDR 网段写法。

## 牛客身份历史

迁移会保存迁移时仍绑定的牛客 UID 与账号的归属，之后解绑也不会释放归属。若迁移之前已经解绑并删除了绑定行，数据库可能没有留下 UID 与原账号的对应关系；上线前应人工核对这部分历史记录，不能声称已经恢复无法追溯的数据。账号转移由管理员线下处理并审计，不支持用户自助转移。

## 测试与部署

数据库集成测试只在 `account.database-check=true` 时运行，创建随机命名的临时数据库；判题集成测试只在 `practice.sandbox-check=true` 时运行。普通单元测试不会自动覆盖这两类测试。当前是单实例会话撤销机制，多实例部署前需要共享会话或账号版本控制。正式服务必须使用 HTTPS、独立密钥并限制数据库和 Redis 的公网访问。

牛客历史提交新增原 UID 快照：新记录在写入时保存 UID；旧记录只从仍存在的绑定或同步任务回填，无法确认来源的记录保留为“归属未知”。本人可以按历史 UID 查看，其他访客与公开排行榜仅显示当前已审核绑定 UID 的记录。首次 UID 仅在管理员批准后永久锁定。迁移以前已经解绑且审核历史无法证明的旧归属不会自动释放，应由管理员核实。
