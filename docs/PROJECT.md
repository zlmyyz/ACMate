# PROJECT

## 解决的问题

ACMate 为校内程序设计竞赛社提供统一的训练与题解交流平台。社团成员可以查看训练计划、记录解题进度、参与讨论区交流。

## 权限模型

- 所有账号默认为普通用户
- app_user.is_admin=1 的用户额外拥有管理员权限
- 管理员同时也是普通用户

## 第一版业务范围

- 用户基础管理
- 题目与训练计划
- 讨论区（帖子、评论、点赞）
- 外部 OJ 账号绑定与提交同步（Codeforces 自动同步，牛客仅绑定）
- 基于首次通过题目数量的排行榜

## 明确不做

- 多社团 / 多租户
- 动态 RBAC（不存在 role、user_role、permission 表）
- 在线判题系统
- 前端（第一版仅后端 API）
