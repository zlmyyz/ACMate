小红的网格图构造2.0 (Grid Graph Construction)

timer Time Limit: 1000ms memory Memory Limit: 256MB Difficulty: 1400 Acceptance: 42%
description Description history Submissions forum Discussion (12) lightbulb Editorial

Problem Statement

Given an integer $N$, construct an $N \times N$ grid containing only the characters 'R', 'G', and 'B' such that:

  • No two adjacent cells (horizontally or vertically) contain the same character.
  • The number of 'R's, 'G's, and 'B's in the grid are as close to each other as possible. Specifically, the difference between the maximum and minimum count among the three characters should be at most 1.

If there are multiple valid grids, you can output any of them.

Input Format

A single line containing a single integer $N$ ($1 \le N \le 1000$).

Output Format

Print $N$ lines, each containing a string of length $N$ consisting of characters 'R', 'G', and 'B', representing the constructed grid.

Example 1

Input 
3
Output 
RGB
BRG
GBR
Explanation: In this $3 \times 3$ grid, there are 3 'R's, 3 'G's, and 3 'B's. No two adjacent cells share the same color.
